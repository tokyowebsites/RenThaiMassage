## 🔌 Squarespace Booking Integration

### Setup Steps:
1. Get your Squarespace API key from [Squarespace Developer Portal](https://developers.squarespace.com/)
2. Open `/src/lib/squarespace.ts`
3. Replace `YOUR_SQUARESPACE_API_KEY` with your actual API key
4. Update `siteUrl` to match your Squarespace site URL
5. Map service IDs to your Squarespace service IDs
6. Test the booking flow
